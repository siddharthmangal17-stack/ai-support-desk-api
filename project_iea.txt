14. Testing Checklist
Test these cases:

User can register.
Duplicate email is rejected.
Wrong password is rejected.
Unauthenticated users cannot create tickets.
Customer cannot view another customer’s ticket.
Agent cannot access admin APIs.
Empty ticket title is rejected.
Agent can update assigned tickets.
Admin can assign tickets.
Invalid AI output uses fallback values.
AI API failure does not prevent ticket creation.
Resolved tickets can be reopened by customers.
Closed tickets cannot receive comments.
